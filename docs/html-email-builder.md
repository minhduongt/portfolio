# HTML preview and email builder

The `html-email-builder` component is implemented as a browser utility with a separate lazy-loaded bundle. Its catalog payload is included in [new-tools-catalog.json](./new-tools-catalog.json), defaulting to private for admin review. The existing backend metadata schema already supports this component key. Choose public, limited or private visibility in the admin editor as usual.

The builder provides Welcome, Newsletter and Receipt templates. They use table layouts, system fonts and inline CSS, without external assets. Users can edit brand, document title/subject, heading, message, accent color, call-to-action text/URL and footer. Receipt fields add order reference, item description and total. Template text is HTML-escaped, accent color is validated, and button URLs must use HTTP/HTTPS. Click Apply template to generate the source; this explicit action replaces current HTML edits. Selecting a template alone does not replace the edited source.

Direct HTML editing updates the live preview. Desktop and mobile modes use 600px and 375px iframe widths; narrow containers allow horizontal scrolling without overflowing the whole page. Copy and Download HTML preserve the edited source. The tool does not send email, and the document title is not an actual email subject header. Email clients may render the markup differently from a browser.

Preview isolation uses a sandboxed iframe without scripts or same-origin privileges, a dedicated DOMPurify instance, removed navigation/resource attributes and a restrictive CSP. Scripts, forms, embedded frames, refresh metadata and external image URLs are removed. Inline CSS and embedded data images remain available. CSS resource attempts are blocked by CSP; they may appear as failed `csp` requests in developer tools but do not receive network responses. Preview CSS cannot style the portfolio. Export is the original edited HTML rather than the sanitized preview document.

Validation: `node scripts/check-email-builder.mjs` against the root build preview on port 4177 (override `SITE_URL`) checks all templates, text customization and escaping, invalid URLs/colors, preview sandbox/CSP, parent-page isolation, blocked assets, preserved download contents, both preview widths and five screen sizes. Existing developer-tool browser checks, content-contract checks and Hosting checks also pass. No emails, live tool records or deployments were performed.
